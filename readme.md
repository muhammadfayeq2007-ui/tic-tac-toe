# 🎮 Tic-Tac-Toe

A responsive two-player Tic-Tac-Toe game built with **HTML, CSS, and Vanilla JavaScript**.

## ✨ Features

* Two-player gameplay
* Custom player names
* Win and tie detection
* Prevents moves on occupied tiles
* Replay/reset functionality
* Responsive design
* Glassmorphism/neon-inspired UI

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6+)

## 🧠 JavaScript Concepts

This project helped me practice:

* Factory functions & closures
* DOM manipulation
* Event handling & event delegation
* Arrays and array methods
* Game state management
* Separation of game logic and UI

## 🚀 Running the Project

No dependencies or frameworks are required.

Open `index.html` in your browser and start playing.
